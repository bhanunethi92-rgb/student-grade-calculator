## 📌 Overview

A simple Python-based application that calculates a student's **total marks, average percentage, and grade**.
This project demonstrates core programming concepts and is ideal for beginners.

---

## 🚀 Features

* 📥 Accepts marks for multiple subjects
* 🧮 Calculates total and average
* 🏆 Assigns grade automatically
* ✅ Clean and readable logic
* 🎯 Beginner-friendly implementation

---

## 🛠️ Tech Stack

* **Language:** Python 3

---

## ⚙️ How It Works

1. Enter marks for each subject
2. Program calculates:

   * Total marks
   * Average percentage
3. Grade is assigned based on average:

| Average (%) | Grade |
| ----------- | ----- |
| 90 – 100    | A     |
| 75 – 89     | B     |
| 50 – 74     | C     |
| Below 50    | D     |

---

## 💻 Example

**Input:**

```bash
Subject 1: 85
Subject 2: 78
Subject 3: 92
Subject 4: 74
Subject 5: 88
```

**Output:**

```bash
Total: 417
Average: 83.4
Grade: B
```
